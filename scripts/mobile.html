Piloter le bureau au doigt

  • Touch : tapez pour cliquer, glissez pour défiler une page, appui maintenu pour glisser un objet.
  • Pavé : le doigt déplace le curseur, tape pour cliquer.
  • À deux doigts : pincez pour zoomer, glissez pour défiler.
  • Le bouton rond à droite passe en plein écran — déplacez-le où vous voulez.
