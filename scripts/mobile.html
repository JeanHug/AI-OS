Piloter le bureau au doigt

  • Tapez pour cliquer ; glissez pour défiler une page ; appui maintenu puis glisser pour déplacer un élément ; appui long = clic droit.
  • À deux doigts : pincez pour zoomer, glissez pour défiler (ou déplacer la vue zoomée), deux taps = clic droit, deux double-taps = zoom 1×.
  • Le clavier s'ouvre tout seul dès qu'un champ texte est actif — trois doigts pour le forcer.
  • L'écran s'adapte automatiquement au format de votre appareil.
